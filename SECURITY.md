# Security Policy & Vulnerability Disclosure (ISO/IEC 27001 & ISO 42001 A.9)

## 1. Zero Data Retention & Privacy Protection
This repository and its associated governance prototypes adhere to strict **Data Minimization** and **Zero Data Retention (ZDR)** principles:
* No User Personal Data (PII) is stored or logged.
* In-memory session processing only; session data is purged immediately upon completion.
* Full alignment with the Hong Kong Personal Data (Privacy) Ordinance (PCPD) and EU GDPR Article 5.

## 2. Reporting a Vulnerability
If you discover a security vulnerability or guardrail bypass within these governance prototypes:
1. Please **do not** open a public issue.
2. Direct report via [Jacky Law on LinkedIn](https://www.linkedin.com/in/jackylawck).
3. Reports will be acknowledged within 48 hours, and remediation measures published within 7 business days.
